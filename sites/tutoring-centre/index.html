    How a class runs

    Every class runs in the same order. A tutor teaches one method, your child practises it on paper, then explains it back out loud. If they can explain it, they can use it in the exam.

    One room, four 11+ subjects

    Year 3 starts with maths and English. Verbal and non-verbal reasoning join in Year 4. Year 5 sits timed papers in GL Assessment and CEM styles, which differ by region.

    The 11+ is demanding and no tutor can promise a grammar school place. We promise the same table each week and a written report each term.
